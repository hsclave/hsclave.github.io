■ 루트의 service-worker.js 에 대해 (중요)
----------------------------------------
예전에는 APOLLON 이 루트(/)에 있어서 태블릿에
scope "/" 로 service worker 가 등록돼 있습니다.
그냥 두면 옛 화면을 계속 물고 있게 됩니다.

새 루트 service-worker.js 는 그 옛 등록을 스스로 해제하고
옛 캐시(apollon-v1~v5)를 지운 뒤 사라지는 파일입니다.
한 번 실행되고 없어지므로 나중에 지우셔도 됩니다.

이 때문에 /apollon/ 의 캐시 이름은 apollon-v6 으로 올려두었습니다.
(정리용 파일이 v5 까지만 지우도록 되어 있습니다)


■ 태블릿 재설치 (APOLLON 만 해당)
----------------------------------------
APOLLON 은 시작 주소가 / 에서 /apollon/ 으로 바뀌었기 때문에
설치된 앱을 지우고 새로 설치해야 합니다.

  1. 태블릿에서 APOLLON 아이콘 길게 눌러 삭제
  2. Chrome 으로 https://hsclave.github.io/ 접속
  3. "제품 검사 성적서" 선택 → 메뉴 → 홈 화면에 추가
  4. 같은 방식으로 "설치완료보고서" 도 추가

  ※ 기록(localStorage)은 도메인 기준으로 저장되므로
    경로가 바뀌어도 그대로 남아있습니다.


■ 두 앱이 한 도메인에 공존하도록 처리한 것
----------------------------------------
  1. 경로 분리
     각자 자기 폴더에 있어 파일 이름이 겹치지 않음

  2. 상대경로
     manifest 의 start_url/scope, service worker 의 캐시 목록을
     상대경로로 변경 → GitHub 하위 경로와
     데스크탑 앱 서버(APOLLON 8766 / F7141 8768 루트) 양쪽에서 동작

  3. 캐시 분리
     service worker 가 캐시를 정리할 때 caches.keys() 는
     도메인의 모든 캐시를 돌려줍니다. 그대로 두면 한 앱이
     갱신될 때마다 다른 앱 캐시를 지웁니다.
     각자 자기 접두어(apollon- / f7141-) 만 정리하도록 수정.

  4. 데이터 분리
     APOLLON : localStorage 의 apollon_v3
     F7141   : localStorage 의 f7141_install_v1
     키가 달라 도메인이 같아도 기록이 섞이지 않습니다.


■ 검증한 내용
----------------------------------------
로컬에 이 구조를 그대로 재현해서 실제 브라우저로 확인했습니다.

    새 구조로 교체 → 루트 재방문 시 옛 SW 등록 해제, 옛 캐시 삭제 확인

  · 두 앱에 각각 기록 저장 → 서로 섞이지 않음 확인
  · 비행기 모드에서 두 앱 모두 정상 실행
